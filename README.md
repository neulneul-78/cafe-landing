# ☕ cafe-landing

늘늘 카페의 간단한 랜딩 페이지 예제 프로젝트예요. 순수 HTML/CSS로만 만들어서 별도 설치 없이 바로 열어볼 수 있어요.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터가 담긴 메인 페이지 |
| `style.css` | 갈색 톤 디자인과 모바일 대응 스타일 |

## 사용법

`index.html`을 브라우저(크롬 등)로 열면 돼요.

## 참고

- 주소, 전화번호, 가격은 모두 샘플 데이터예요.
- AI 에이전트 수업 실습용으로 만들었어요.
